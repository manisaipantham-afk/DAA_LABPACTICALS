## Aim

Implement Chain Matrix Multiplication using Dynamic Programming.

## Algorithm

1. Create a DP table.
2. Consider different ways to split the matrix chain.
3. Calculate the multiplication cost for each split.
4. Store the minimum cost in the DP table.
5. Return the minimum number of multiplications.

## Example

**Input:**

```text
Matrices = 3
Dimensions = 10 20 30 40
```

**Output:**

```text
Minimum number of multiplications = 18000
```

## Complexity

* Time: `O(n³)`
* Space: `O(n²)`
